# Contributing to PetBuddy

Welcome! PetBuddy is open source and we welcome contributions.

## Getting started

See [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md) for the current build plan and [docs/DESIGN.md](docs/DESIGN.md) for the architecture.

## Quick start

```bash
git clone https://github.com/bsreeram08/petbuddy.git
cd petbuddy
swift test
```

## How to contribute

### Bug reports
Open a GitHub issue with:
- macOS version
- Steps to reproduce
- Expected vs actual behavior

### Pet packs
See [docs/PETPACK_SPEC.md](docs/PETPACK_SPEC.md) for the `.petpack` format spec. Pet packs can be submitted as PRs to the `Pets/` directory or as standalone repositories linked from PETS.md.

### Code
1. Fork the repo
2. Create a branch: `git checkout -b feat/my-feature`
3. Make your changes
4. Run `swift test`
5. Open a PR

## Code of conduct

Be kind. This is a project that brings joy to people — keep it that way.
