# PetBuddy

Desktop pet companion for macOS. Lives on your screen as a reminder that people love you.

## Status

Pre-alpha. See [PROJECT_PLAN.md](docs/PROJECT_PLAN.md) and [DESIGN.md](docs/DESIGN.md) for details.

## Pet Packs

Default pet pack is at `Pets/Goldie.petpack/`. Drop additional `.petpack` directories into `Pets/` to add more pets.
